# Dialogflow CX Spanish Bot Evaluation Toolkit

A reproducible toolkit for designing and evaluating a Spanish conversational AI bot using Dialogflow CX concepts, with a focus on NLU quality, conversation design, fallback behavior, escalation, QA, and secure API configuration.

## Overview

The Dialogflow CX Spanish Bot Evaluation Toolkit is an independent portfolio project designed to demonstrate practical skills in conversational AI, NLU evaluation, Dialogflow CX architecture, linguistic QA, and secure API configuration.

The project combines two complementary layers:

1. conversational design and evaluation;
2. technical configuration for Dialogflow CX integration.

The initial use case is a Spanish-language school support bot for family-facing administrative guidance in a Chilean educational context.

## Main Objectives

The project aims to demonstrate practical understanding of:

- Dialogflow CX agents;
- flows and pages;
- intents and training phrases;
- entities and parameters;
- transition routes;
- fallback behavior;
- escalation to human support;
- fulfillment logic;
- NLU testing;
- conversational QA;
- Spanish-language variation;
- secure environment configuration;
- API credential handling.

## Initial Use Case

The initial bot supports administrative and informational requests related to school support services.

Example use cases include:

- asking about support services;
- requesting an interview with a professional;
- asking which documents are required;
- reporting an absence;
- asking about support schedules;
- requesting contact information;
- asking about referral procedures;
- requesting human assistance;
- handling out-of-scope or ambiguous requests.

The bot is designed for evaluation and portfolio purposes only. It does not use real student data.

## Evaluation Areas

The toolkit evaluates:

1. Intent Accuracy
2. Entity Extraction
3. Flow Completion
4. Fallback Quality
5. Escalation Appropriateness
6. Response Clarity
7. Tone and Linguistic Quality
8. Safety and Privacy
9. User Usefulness
