# Dialogflow CX Spanish Bot Evaluation Toolkit

Toolkit reproducible para diseñar y evaluar un bot conversacional en español utilizando conceptos de Dialogflow CX, con foco en calidad NLU, diseño conversacional, fallbacks, escalamiento, QA y configuración segura de API.

## Descripción general

Dialogflow CX Spanish Bot Evaluation Toolkit es un proyecto independiente de portfolio diseñado para demostrar competencias prácticas en IA conversacional, evaluación NLU, arquitectura de Dialogflow CX, QA lingüístico y configuración segura de API.

El proyecto combina dos capas complementarias:

1. diseño y evaluación conversacional;
2. configuración técnica para integración con Dialogflow CX.

El caso de uso inicial es un bot de apoyo escolar en español para orientación administrativa dirigida a familias, situado en contexto educativo chileno.

## Objetivos principales

El proyecto busca demostrar comprensión práctica de:

- agentes de Dialogflow CX;
- flows y pages;
- intents y training phrases;
- entities y parameters;
- transition routes;
- fallbacks;
- escalamiento a apoyo humano;
- lógica de fulfillment;
- pruebas de NLU;
- QA conversacional;
- variación lingüística del español;
- configuración segura de entorno;
- manejo de credenciales de API.

## Caso de uso inicial

El bot inicial atiende solicitudes administrativas e informativas relacionadas con servicios de apoyo escolar.

Ejemplos de uso:

- consultar servicios de apoyo;
- solicitar entrevista con un profesional;
- preguntar qué documentos se requieren;
- informar una inasistencia;
- consultar horarios de atención;
- pedir información de contacto;
- preguntar por procedimientos de derivación;
- solicitar asistencia humana;
- manejar solicitudes ambiguas o fuera de alcance.

El bot está diseñado únicamente con fines de evaluación y portfolio. No utiliza datos reales de estudiantes.

## Áreas de evaluación

El toolkit evalúa:

1. Precisión de intención
2. Extracción de entidades
3. Completitud del flujo
4. Calidad del fallback
5. Adecuación del escalamiento
6. Claridad de respuesta
7. Tono y calidad lingüística
8. Seguridad y privacidad
9. Utilidad para el usuario
